3. **Safari's 7-day storage wipe for non-installed sites** (`UX_Flows.md` §7, `Product_Scope.md` §7 decision 9). Confirm from WebKit's own documentation whether script-writable storage (localStorage, IndexedDB) is still cleared after 7 days without a visit, and whether an installed home-screen web app is exempt. This is a docs check; a live test would take a week.
